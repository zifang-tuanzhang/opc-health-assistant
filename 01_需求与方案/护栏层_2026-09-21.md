## 0. 一句话

产出不是"一次生成就交付"，而是**生成 → 结构性校验 → 不合格就把问题编码回灌给模型 → 模型自己改 → 最多 N=2 轮 → 仍不合格则降级交付（带警示，不崩溃）**。
代码只当"镜子 + 提醒"，**绝不替模型写事实、绝不预设答案**——这是与上届"硬编码事实分支导致模型零思考空间"的本质区别。

---

## 1. 三层职责（左 / 中 / 右）

| 层 | 谁 | 管什么 | 判不判事实真假 |
|---|---|---|---|
| 左侧·网关边界 | `src/guard.py` | 空输入 / 超长 / 危险协议 / 限流 / 安全头 | 不管（纯输入形状） |
| 左侧·产出校验 | `src/guardrails.py` | 4 段式结构 / 来源必填 / 边界词 / 紧急词 / 禁断言 / 诚实标注 / 检索真实性 | **绝不判**（🔴 红线） |
| 右侧·事实真假 | 不做（代码层面） | 某医院是否真有某科室/资源 | 只能靠来源链接 + 人工/评委核验 |

> 🔴 **越过左侧边界的后果**：一旦代码去判"某医院是否真有心血管内科"，就重蹈上届死法（代码判断事实 → 模型被架空 → 零思考空间 → 垫底）。因此本层只做**结构与边界词**校验。

### 2.1 规则清单（R1~R10）与判据

| 规则 | 名称 | 判据（全是"左侧"） | 违规后果 |
|---|---|---|---|
| R1 | 结构完备 | `query_condition` 非 null；`usage_tips` 非空；不得空壳（**澄清轮豁免**：正在询问用户条件时，条件本身就该是缺的） | 打回 |
| R2 | 来源必填 | 每条 `query_results` 必须带 `source.title` + `source.url`，且 URL 匹配 `^https?://` | 打回 |
| R3 | 来源可达 | 轻量 HEAD/GET 探测；**默认关闭**（`OPC_GUARDRAIL_VERIFY_URLS=1` 开启），防弱网假阳性 | 打回 |
| R4 | 边界拒答 | 用户问诊断/用药时：产出须含"不诊断/不用药 + 就医引导"，且不得出现用药建议模式或剂量 | 打回 |
| R5 | 紧急优先 | 命中紧急词（胸痛/昏迷/大出血/轻生…）时，产出必须含 `120` | 打回 |
| R6 | 禁断言 | 不得出现"目前可提供/可预约成功/确定出诊/包治"等无检索支撑的绝对化表述 | 打回 |
| R7 | 空字段诚实 | 结果/说明不得留空；无结果时须标"暂未查到/待核实"（**边界拒答、急救指引、条件澄清轮三类豁免**） | 打回 |
| R8 | 检索真实性 | 有结果/来源，但 `retrieval_log` 零命中 → 判为"以记忆冒充联网检索" | 打回 |
| R9 | 易变资源三态 | 用户问血清/血库/床位/号源等易变资源时，每条结果必须标 `info_status` 三态之一 | 打回 |
| R10 | 院区纪律 | 用户提到院区（命中通用院区词）时，每条结果必须标明**适用院区**（`campus` 字段，或在名称/说明中写清） | 打回 |

> 词表全部是"**触发词**"（判断该不该触发某条规则），不含任何医院/科室/医生结论。
> R8 是**本届比赛红线**（"不得硬编码冒充动态查询"）的代码化落点。
>
> **R9 / R10 的判据补充说明**：
> 两条都是"**命中触发词才校验**"的同构模式（不对所有提问都强制），避免变成"总在误报的闸门"。
> `CAMPUS_WORDS` 只放**通用院区词**（院区/分院/本部/总院/东南西北院区…），
> **不放任何具体院区名**——具体院区名属"医院事实"，代码一律不得硬编码。
> R10 只回答"有没有把院区讲清楚"，**不回答"讲的那个院区对不对"**（后者是模型与来源的职责，
> 与 R1~R9 一样，"只查左侧、不查事实"）。
> 二者的依据：赛题《基础需求2》「不同院区的地址、科室和医生安排不得混用」、
> 《基础需求3》「科室信息应包含医院及院区」「出诊信息应标明适用院区」——同属"基础验收内容"。

> **「澄清轮」豁免（2026-09-21 新增，2026-09-21 晚二次重构为字段声明）**：
> 用户缺**会实质影响检索**的条件（科室/医院/资源类型等；**地区为固定演示范围，不视为缺失**）、模型正在澄清时，本轮称为**澄清轮**。
> 此时 **R1（须给条件）与 R7（空结果须标注「暂未查到」）豁免**——因为这两条针对的是
> "有条件/有结果时该怎么说"，而澄清轮**本来就没有条件、没有结果**；
> 硬套会让一句正常的澄清被**连环打回至超限降级**
> （实测打回序列：R7 → R1 → R8 超限降级，用户最终看到的是"输出未完全满足结构性约束"，
> 而真正该问的话反而没能说出口）。
> ⚠️ 豁免的**只是**"允许没有条件 / 允许没有结果"，**不豁免任何编造**：
> 澄清轮若塞了 `query_results`，仍会被 **R8**（检索真实性对账）打回。
> 触发方式（二次重构后）：编排层读模型首轮 JSON 的 **`need_clarification` 字段**（未检索且声明为真）→ 传 `clarify=True`；
> **判定来自字段，不猜措辞**（修复首版"询问形态词 × 地区目标词共现"的词表硬编——变化维度大、列不全必漏）。

### 2.2 控制循环时序

```
用户提问
  └─(1) 输入护栏（guard）→ 空/超长/危险协议 → 直接拒
  └─(2) 编排 run_turn
        ├─ 阶段1「能力调用」：模型自决是否检索 → web_search（真联网）→ 写 retrieval_log
        └─ 阶段2「生成 + 护栏循环」（最多 N=2 轮打回）
             生成 4 段式 ─→ Validator 校验
               ├─ 通过 ────────────────→ 交付（reflection_count=k，degraded=False）
               └─ 不通过 & 还有轮次 ──→ 写 guardrail 留痕 → 把 violations+hints 回灌
                                          → 模型"仅重新组织语言"再生成（不重新检索）
               └─ 不通过 & 已到 N=2 ──→ 写 degraded 留痕 → 追加 ⚠️ 提示 → 仍交付
```

**关键设计**：打回时**不重新检索**（`编排层` §2.4.2 明确），只让模型重新组织语言 —— 避免"无限检索烧钱 + 越搜越乱"。

| 测试文件 | 项数 | 结果 |

覆盖的关键场景：

- **打回 N=2 后降级**：`reflection_count=2`、`degraded=True`、留痕三条（reject, reject, degraded）、仍带 ⚠️ 提示；
- **打回 1 轮后改好**：`reflection_count=1`、`degraded=False`；
- **一次通过**：`reflection_count=0`；
- **编造被 R8 拦截**：检索为空却给出带链接结果 → 连打 2 轮仍不改 → 降级；
- **解析失败纳入同一套机制**：模型输出非法 JSON → 也走"打回—重生成"。

> 用「注入假客户端」而非"等模型犯错"，是为了**确定性**：让每一条规则的触发与打回/降级路径每次都能复现。

## 5. 诚实标注的局限（做不到就说）

1. **未能用真实模型复现"护栏打回"**：真实模型在强化提示下表现良好，没有自然违规；因此 N=2 打回/降级路径的证据来自注入式确定性测试，而非真实模型实测（见 §3.3）。
2. **R3（来源可达）默认关闭**：需联网逐条探测，弱网/受限网络下假阳性高。当前用"R2 链接格式合法 + R6 禁断言"间接保障；需要时用 `OPC_GUARDRAIL_VERIFY_URLS=1` 开启。
3. **R4 拒答判定偏宽**：`就医` 一类引导词较宽，可能漏掉"用委婉话术给用药建议"的模型。收紧需引入语义判定（超出"左侧"边界，按红线不做）。
4. **词表是中文关键词匹配**：模型用英文/同义改写绕过词表时不会触发。这是"左侧规则"的固有上限，最终仍需人工/评委核验。
5. ~~**真实检索仍受本沙盒网络限制**（DuckDuckGo 被拦、Bing/百度返回反爬页）~~ → **已解决**：检索层改为 360 搜索（桌面版/移动版）+ 搜狗后，本机实网已取到真实医院来源（见 `03_测试记录/真实性证据_2026-09-21.md`）。当前限制变为「持续高频下会被风控」，属公开页面检索的固有代价。
6. ~~**澄清轮的认定依赖模型第一轮的表述**（词表共现）~~ → **已二次重构为字段声明（2026-09-21 晚）**：澄清轮改由模型在首轮 JSON 顶层**显式声明 `need_clarification=true`** 触发，编排层读字段、不猜措辞（见 §4 第 10 条 / 二次重构豁免段）。模型用**任何说法**声明该字段即被识别为澄清轮，不再依赖"询问形态词 × 地区目标词共现"旧词表（旧版词表变化维度大、列不全必漏）。因此「模型不说询问话术就不认澄清轮」这一上限**已消除**。唯一保留的行为：模型若**既不检索、又不声明**该字段，则编排层按"条件已足"直接检索（地区固定演示范围昆明、不追问）——这是**产品决策**（本地化平台定位），不是缺陷。
