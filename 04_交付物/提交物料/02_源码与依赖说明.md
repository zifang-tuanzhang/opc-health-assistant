## 三、依赖清单

### 3.1 后端依赖（`02_源码/requirements.txt`）

| 依赖 | 版本约束 | 用途 |
|---|---|---|
| `fastapi` | `>=0.110,<1.0` | Web 框架：API 网关与 `/chat`、`/health` 端点 |
| `uvicorn[standard]` | — | ASGI 服务器：本地启动与容器运行 |
| `pydantic` | `>=2.0` | 请求与响应模型：4 段式输出契约 |
| `httpx` | `>=0.27` | HTTP 客户端：调用搜索与模型接口 |
| `python-dotenv` | `>=1.0` | `.env` 加载：密钥的服务端环境变量化 |
| `openai` | `>=1.40` | 模型客户端：国内厂商均为 OpenAI 兼容网关，一套 SDK 通用 |
| `pytest` | `>=8.0` | 自动化测试 |

### 3.2 离线依赖轮子（`wheels/`）

目录内提供 **51 个预编译安装包**（`.whl`），覆盖 Python 3.10 / 3.11 / 3.12 / 3.13 四个版本，
用于在**不联网**的评审环境中完成依赖安装。启动器默认优先从该目录离线安装。

实际运行安装的依赖项为 34 个（含上述 7 项的传递依赖）；轮子数量多于依赖项数量，是因为同一依赖为多个 Python 版本各准备了一份。

### 3.3 前端

无第三方前端依赖，无构建步骤，浏览器直接加载。

### 4.2 联网搜索工具

| 项 | 内容 |
|---|---|
| 依赖的第三方 SDK 或 API | **无**。检索层自行请求公开搜索页面并解析返回内容 |
| 需要的账号或额度 | **无**。不需要申请任何搜索接口 |
| 默认后端与回退顺序 | `so360` → `mso360` → `sogou` → `sm` |

| 后端标识 | 服务名称 | 返回的链接粒度 | 是否默认启用 |
|---|---|---|---|
| `so360` | 360 搜索（桌面版） | 文章级真实来源网址 | 是（首选） |
| `mso360` | 360 搜索（移动版） | 文章级真实来源网址 + 发布日期 | 是 |
| `sogou` | 搜狗搜索 | 域名级真实来源网址 + 发布日期 | 是 |
| `sm` | 神马搜索（移动版） | 文章级真实来源网址 | 是 |
| `ddg` | DuckDuckGo（一款海外搜索引擎，国内不可达） | — | 否（保留在代码中，默认不启用） |

按顺序回退，首个有结果的后端即被采用；全部失败时返回空结果，由诚实降级路径兜底，不生成替代性答案。

> **关于 `ddg` 默认关闭**：该后端在国内不可达，每次外呼需等待完整超时。代码保留该实现，但默认不列入启用列表。
> 实测影响见《使用与架构说明》第六节「检索总耗时预算」。

## 五、环境配置示例

配置示例文件为 `02_源码/deploy/.env.example`，**全部为可选项，零配置即可启动**。
复制为 `02_源码/deploy/.env` 或 `02_源码/src/.env` 后按需填写。

常用配置项：

```ini
# ── 运行环境 ──
OPC_HOST=127.0.0.1              # 监听地址，默认仅本机回环
OPC_PORT=8137                   # 服务端口，被占用时启动器自动顺延
OPC_DEMO_CITY=昆明              # 默认检索范围

# ── 检索层 ──
OPC_SEARCH_BACKENDS=so360,mso360,sogou,sm
OPC_SEARCH_BUDGET_SECONDS=18    # 单次检索外呼总耗时上限（秒）

# ── 模型接口（回落位，主路径为页面内配置的密钥库）──
OPC_LLM_API_KEY=
OPC_LLM_BASE_URL=
OPC_LLM_MODEL=

# ── 运行保障 ──
OPC_LLM_DAILY_BUDGET_TOKENS=1000000
OPC_LLM_CACHE_TTL_SECONDS=86400
OPC_LLM_RATE_LIMIT_PER_MIN=30

# ── 网关边界 ──
OPC_MAX_MESSAGE_LEN=500
OPC_RATE_LIMIT_PER_MIN=300
```

完整说明（含每项的含义、推荐取值与注意事项）见该文件内的注释。

## 六、密钥处理

赛题要求「不提交真实密钥」，本作品的处理方式如下：

| 项 | 做法 |
|---|---|
| 密钥存放位置 | `%USERPROFILE%\.opc_health\keys.json`，位于**项目目录之外** |
| 配置入口 | 页面右上角「模型密钥」入口，填写后立即校验连接可用性 |
| 容器场景的替代方式 | 通过环境变量提供（容器内无用户目录） |
| 版本库 | 密钥不写入项目文件夹，`.gitignore` 另设拦截规则双保险 |
| 交付包 | 打包脚本内置泄漏自检，排除 `.env`、`keys.json` 及疑似密钥文件 |
| 日志 | 日志输出自动脱敏 |

**三方核查结果**：交付包内 76 个文本文件经逐字节扫描，密钥特征串命中数为 **0**；
版本库历史与工作区文件同样为 0 命中。核查方法与结果见 `03_测试记录/交付包验收_2026-09-21.md`。

`keys/providers.preset.json` 只包含服务名称、接口地址、可用模型名等配置元数据，**不包含任何密钥值**。

## 七、复现步骤

### 7.1 环境隔离与依赖安装

```bash
cd 02_源码
python -m venv .venv                      # Windows
# python3 -m venv .venv && source .venv/bin/activate    # macOS / Linux

# 优先使用包内离线轮子安装（无需联网）
.venv/Scripts/python.exe -m pip install --no-index --find-links ../wheels -r requirements.txt

# 或直接在线安装
pip install -r requirements.txt
```

### 7.2 启动服务

```bash
cd 02_源码
python -m uvicorn src.server:app --host 127.0.0.1 --port 8137
```

或直接双击项目根目录的 `启动项目.bat`（自动完成建环境、装依赖、启动三步）。

### 7.3 运行测试

```bash
cd 02_源码
python 跑全部测试.py --offline     # 离线九套，不需密钥、不需联网
python 跑全部测试.py               # 全部十二套（离线九套 + 实网三套，需联网与已配置密钥）
python 跑全部测试.py --json out.json
```

> `--offline` 是较小的集合。仅报离线结果会少算三套实网证据，对外引用请使用完整档。

### 7.4 容器方式

```bash
cd 02_源码/deploy
docker compose up -d          # 首次构建需联网获取基础镜像
```
