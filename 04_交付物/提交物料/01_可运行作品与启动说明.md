# 可运行作品与启动说明

> 对应赛题《基础需求 7 · 交付物与工程要求》第 1 项：
> 「可运行作品：提供 Web 页面、智能体平台预览入口或其他可交互入口。线上入口应自提交起至少 7 天可用；
> 无法公网部署时，可提供含交互界面的本地一键运行包，确保评审在 15 分钟内按说明启动。」
>
> 作品名称：AI 医院资源查询与便民就医助手 ｜ 文档日期：2026-09-24

---

## 一、运行形态

本作品以 **本地一键运行包** 形式提交，包含完整的交互界面与后端服务。

| 项 | 说明 |
|---|---|
| 交互入口 | 浏览器页面（主交互页），启动后自动打开 |
| 启动方式 | 双击 `启动项目.bat` |
| 依赖获取 | 包内已内置 **51 个离线依赖轮子**，无需联网安装 |
| 搜索接口 | 不需要申请任何第三方搜索接口，检索走公开搜索页面 |
| 模型密钥 | 由使用者自备，在页面内填写 |
| 监听地址 | 默认 `127.0.0.1:8137`（仅本机回环，局域网内其他设备无法访问，属刻意的安全默认值） |

**关于线上入口**：本作品未做公网部署，因此按赛题允许的方式提供本地一键运行包，并在第二节给出实际计时的启动流程。

---

## 二、环境要求

| 项 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10 / 11（64 位） | 离线依赖包为 Windows 64 位轮子；其他系统见第五节 |
| Python | **3.10 及以上** | 安装时需勾选 `Add python.exe to PATH` |
| 浏览器 | Edge / Chrome 任一 | 用于打开交互界面 |
| 网络 | 可选 | 不联网也可启动；**要获得真实检索结果需要联网** |

检查 Python 是否已安装：按 `Win + R`，输入 `cmd` 并回车，在命令提示符中输入 `python --version`。
显示 `Python 3.x.x` 且不低于 3.10 即可。若提示「不是内部或外部命令」，见第六节。

## 三、启动步骤

### 第 1 步 · 获取作品到本地

三种方式任选一种（内容一致，仅解压后的目录名不同）：

```bash
# 方式一：克隆仓库
git clone https://github.com/zifang-tuanzhang/opc-health-assistant.git
```

```text
方式二：下载 ZIP
仓库页面 → Code → Download ZIP → 解压到任意目录（路径含中文亦可）

方式三：解压交付包
解压 OPC接单吧第三届_交付包_20260924.zip → 得到 OPC接单吧第三届实战能力大赛/ 目录
```

### 第 2 步 · 双击 `启动项目.bat`

启动器会自动完成四项工作，全过程输出中文进度提示：

```text
  ┌────────────────────────────────────────────────
  │ OPC 接单吧 · AI 医院资源查询与便民就医助手 · 启动器
  └────────────────────────────────────────────────
  · Python 就绪：C:\...\python.exe
  · 首次运行：创建虚拟环境 .venv ...
  · 安装依赖（优先离线 wheels）...
  · 启动服务 → 浏览器自动打开
```

**首次运行**会自动创建虚拟环境并从包内离线安装依赖；**后续运行**直接启动，耗时更短。

### 第 3 步 · 配置模型密钥

页面**右上角**有一个常驻的「模型密钥」入口，状态可直接辨认：

| 状态 | 界面表现 |
|---|---|
| 尚未配置 | 琥珀色呼吸闪烁的 `● 未配置模型密钥 · 点此添加` |
| 已配置 | 绿色的 `● <服务商名称> · 更换密钥` |

首次打开页面时会自动弹出操作引导，直接指出入口位置。配置共三步：

1. 在「模型供应商」下拉框中选择服务商（已内置主流国内厂商预设，共 13 家）；
2. 粘贴对应的 API Key；
3. 点击「连接并保存」，系统立即校验连接可用性。

保存后右上角入口变为绿色常亮，此后可随时点击更换。

> **关于界面措辞**：此处显示的是「已配置」，而非「已连接」。后端只做密钥的存在性校验，
> 无法代表服务商侧此刻仍然有效。实际失效时会话链路会返回结构化错误，不虚报状态。

**密钥存储位置**：`%USERPROFILE%\.opc_health\keys.json`（即 `C:\Users\<用户名>\.opc_health\keys.json`），位于**项目目录之外**。
该设计使密钥不会写入项目文件夹，因此不会被误提交至版本库，也不会被打入任何交付包。

### 建议的演示顺序

配置完成后即可提问。以下顺序可依次覆盖各主要功能点：

| 提问 | 覆盖的能力 |
|---|---|
| `昆明哪家医院有心血管内科？` | 真实联网检索，返回多家公立医院 |
| `昆明同仁医院在哪里？怎么挂号？` | 民营医院演示，来源为医院官网，并自动执行同名消歧 |
| `昆明哪家医院有抗蛇毒血清？` | 易变资源，强制标注「历史报道 / 具备能力 / 尚待核实」三态 |
| `云南省第一人民医院心血管内科怎么样？` | 科室信息与来源核验 |
| `我高血压该吃什么药？` | 越界用药问题，拒答并引导就医 |
| `小孩发烧 39 度，该挂哪个科？` | 触发紧急就医提示（120） |
| `北京哪家医院有卒中中心？` | 演示范围之外，如实说明当前仅覆盖昆明 |

**停止服务**：关闭启动器所在的命令行窗口，或在窗口内按 `Ctrl + C`。

## 四、「15 分钟内启动」实测计时

赛题要求评审在 **15 分钟内**按说明启动。本项为实测值，非估算。

**实测方式**：全新目录、全程断网（依赖从包内轮子离线安装）、逐环节计时。

| 环节 | 实测耗时 |
|---|---|
| ① 解压交付包 | 0.2 秒 |
| ② 创建虚拟环境（venv） | 4.5 秒 |
| ③ 离线安装 34 个依赖（不联网） | 18.8 秒 |
| ④ 启动服务到 `/health`（健康检查接口）可响应 | 1.7 秒 |
| **合计（含解压）** | **25.2 秒 ≈ 0.4 分钟** |

**对赛题 15 分钟要求的余量：约 14.6 分钟（97%）。**

说明：

- 计时来自 Windows 环境实测；换机器会因 CPU 与磁盘速度有差异，但「离线装依赖 + 单进程启动」这条路径不含任何需要联网等待的环节，因此不存在网络波动带来的不确定性。
- 上述 25.2 秒为**服务可用**耗时。之后还需一步配置模型密钥（点击右上角入口，粘贴自备的模型 Key），这是交互动作而非等待过程。
- 测得 34 个依赖项对应运行时实际安装集合；包内提供的轮子共 51 个，覆盖 Python 3.10–3.13 四个版本，以便评审机器上的不同 Python 版本均可离线安装。

## 五、其他运行方式

### 容器运行

```bash
cd 02_源码/deploy
docker compose up -d          # 首次构建需联网获取基础镜像
```

访问 <http://localhost:8137/>。容器内没有用户目录，模型密钥改由环境变量提供：
复制 `deploy/.env.example` 为 `deploy/.env`，填入 `OPC_LLM_API_KEY` / `OPC_LLM_BASE_URL` / `OPC_LLM_MODEL`。

### 手动运行（macOS / Linux）

离线轮子只覆盖 Windows 64 位，其他系统使用在线安装：

```bash
cd 02_源码
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt          # 需联网
python -m uvicorn src.server:app --host 127.0.0.1 --port 8137
```

随后访问 <http://127.0.0.1:8137/>。

## 六、运行状态核验与排障

### 6.1 核验要点

| 观察点 | 预期表现 |
|---|---|
| 检索进度时间线 | 逐条显示「正在联网检索「昆明 三甲医院 心血管内科」…」→「检索完成：命中 5 条」；回答产出后自动收拢为一行，点击可复核全过程 |
| 结果中的来源链接 | 为可点击的真实网址，可打开至真实页面，而非拼接生成的占位链接 |
| 追问昆明之外的城市 | 如实告知「当前演示范围仅限昆明」，不编造其他城市的结果 |
| 断网后提问 | 返回「未检索到可核验的公开信息」及空结果，不生成编造内容 |
| 未配置密钥直接提问 | 进入**待配置模式**：提示「未配置模型密钥」并给出配置引导（不发起检索、不调用模型），不伪造答案 |
| 询问「胸口疼挂什么科」 | 优先给出紧急就医提示（胸痛属急症），不给出诊断结论 |

上述行为由代码层护栏约束，不依赖模型自行把握。

### 6.2 常见问题

| 现象 | 原因 | 处理方式 |
|---|---|---|
| 双击后窗口一闪而过 | 未安装 Python，或安装时未勾选 `Add to PATH` | 见 6.3 |
| 提示「未检测到 Python 3.10+」 | 版本过低，或未加入 PATH | 安装 3.10 以上版本并勾选 PATH |
| 依赖安装失败 | 离线轮子与当前 Python 版本不匹配（如 3.14 或 32 位 Python） | 启动器会自动回退在线安装；仍失败时改用 **Python 3.11 或 3.12（64 位）** |
| 提示端口被占用 | 默认端口 8137 已被占用 | 启动器会自动顺延到下一个空闲端口并告知实际端口；也可手动指定：执行 `set OPC_PORT=9000` 后再双击 |
| 浏览器未自动弹出 | 系统默认浏览器被拦截 | 手动访问提示中给出的地址（默认 `http://127.0.0.1:8137/`） |
| 页面提示「尚未配置密钥」 | 正常状态 | 点击「添加密钥」完成配置 |
| 顶部已配置但回答无结果 | 网络不通，或搜索引擎临时限流 | 系统在此情形下不生成替代性答案；检查网络后重试 |
| 连续快速提问后被拦截 | 每分钟模型调用上限保护 | 等待一分钟；阈值可通过 `OPC_LLM_RATE_LIMIT_PER_MIN` 调整 |

### 6.3 Python 未安装时的处理

1. 打开 <https://www.python.org/downloads/>，下载 **Python 3.12（64 位）**（3.10–3.13 均可）；
2. 安装时**务必勾选** `Add python.exe to PATH`（该步骤为必需项，遗漏会导致启动窗口闪退）；
3. 安装完成后重新双击 `启动项目.bat`。

## 七、可调整的运行参数

以下参数均为可选项，零配置即可启动。完整说明与推荐取值见 `02_源码/deploy/.env.example`。

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `OPC_PORT` | `8137` | 服务监听端口；被占用时启动器自动顺延至下一空闲端口 |
| `OPC_HOST` | `127.0.0.1` | 监听地址；改为 `0.0.0.0` 会使服务暴露到局域网，需谨慎评估 |
| `OPC_API_TOKEN` | 空 | 可选网关令牌；设置后，敏感端点（添加密钥 / 重置会话 / 历史记录）需携带令牌方可调用 |
| `OPC_DEMO_CITY` | `昆明` | 默认检索范围 |
| `OPC_SEARCH_BACKENDS` | `so360,mso360,sogou,sm` | 检索后端回退顺序 |
| `OPC_SEARCH_BUDGET_SECONDS` | `18` | 单次检索外呼总耗时上限（秒） |
| `OPC_LLM_RATE_LIMIT_PER_MIN` | `30` | 每分钟模型调用上限 |
| `OPC_MAX_MESSAGE_LEN` | `500` | 单条消息最大长度（字符） |
| `OPC_RATE_LIMIT_PER_MIN` | `300` | 每分钟接口请求上限 |
